Mode d’emploi

Mode d’emploi

Les repères essentiels pour gérer une séance.

Démarrer

  • Choisissez l’activité.
  • Choisissez le format.
  • Ajoutez les élèves ou équipes.
  • Simulez la séance si besoin.
  • Lancez quand le résumé est prêt.

Scores

  • Un score compte seulement après validation.
  • 0-0 doit être validé explicitement.
  • Un match non saisi ne modifie pas le classement.
  • Les exports ne gardent que les matchs validés.

Ladder

  • Le classement suit la montée / descente.
  • Le gagnant monte, le perdant descend.
  • Les terrains arbitres fixes gardent 2 joueurs + 1 arbitre.
  • Le placement initial peut être alphabétique, aléatoire ou manuel.
  • En manuel, un élève déjà placé disparaît des autres menus.

Défi

  • Le classement initial peut être alphabétique, aléatoire ou manuel.
  • Un joueur peut défier dans la plage ±N.
  • La saisie se fait par Victoire de..., sans score chiffré.
  • Si le moins bien classé bat le mieux classé, il prend sa place.
  • La vue compacte permet de voir un maximum d’élèves.

Sports co

  • Suivi par équipes.
  • Choisir championnat, coupe ou poules tournantes.
  • Si aucune équipe n’est au repos, prévoir arbitrage croisé.
  • Les couleurs/dossards peuvent servir de noms d’équipes.

Export

  • En fin de séance, imprimez le classement.
  • Export CSV disponible.
  • Les matchs non validés ne sont pas exportés.
  • Les sauvegardes restent locales dans le navigateur.
